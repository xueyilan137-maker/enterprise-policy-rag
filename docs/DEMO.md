# 本机演示脚本与贡献边界

录屏建议约5–7分钟，先按INSTALL完成本地启动。画面关闭凭据编辑器、Secret窗口与私有日志；只展示原创合成制度和材料。

| 步骤 | 操作 | 应解释的结果 |
|---|---|---|
| 1 | 展示两版合成制度及生效区间 | 日期决定唯一适用版本，制度和数据为合成示例 |
| 2 | 问“住宿标准是多少”，再补完整出差日期 | 缺日期追问；不自动选最新版 |
| 3 | 分别新对话问v1/v2境内住宿标准 | 使用对应库，说明条款与原文；原文回退和生成不同 |
| 4 | 问境外城市能否套B类、未覆盖的婚假 | 能解释范围条款；无制度依据的内容拒答 |
| 5 | 网页上传trip-note-001.md和expense-items-001.csv | CSV确定性解析，文本模型仅生成候选，服务端核验证据/日期/金额 |
| 6 | 发起预审并查看条款/报告 | 预审问题与技术执行状态分开，没有自动核定金额 |
| 7 | 切换财务演示视角保存模拟复核，导出JSON | 独立不可变复核记录，角色选择是开放演示，不是真实登录 |
| 8 | 展示EVALUATION-002/CHATFLOW-005 | 首轮有失败，已见案例转开发；不宣称回答准确率或生产收益 |

录制时使用新的合成申请，不用原用户记录冒充本次新执行。一次报告仅能保存一次复核；没有修改/撤销入口。普通API查询不消耗模型，发起提取与预审会消耗真实调用。不要为演示重复执行reserve-v1首轮入口。

可说明自行实现：合成制度及数据、版本路由和证据校验、限定检索策略、Dify DSL编排、规则API、材料核验、业务持久化与网页、评测门禁和实验记录。Dify平台、通义模型/embedding、向量库、框架和数据库是外部依赖，不写成自研。未验证生产业务、用户规模、节省时长或正式回答准确率。

当前缺口：OCR/扫描件、正式认证和权限配置、跨申请历史票据查重接线、复核更正审计、严格独立评测与真实429/超时故障边界、手机视口。不要在演示或简历中补写为已完成。
